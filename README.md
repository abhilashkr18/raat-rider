# Raat Rider 3D

An open-city 3D taxi game that runs in any phone or desktop browser. No install needed.

## Missions
Airport Run, Midnight Circuit, Cop Hunter, Heat Wave, Fog Cargo Run and Free Roam.

## Controls
- Phone: drag the wheel to steer, drag the 3D view to look around, GUN, MISSILE, NITRO, BRAKE
- Keyboard: A/D or arrows steer, W gas, S brake, Shift nitro, Space gun, E missile, C camera distance, P pause

`classic.html` is the earlier 2.5D version.

## Play online
Repo Settings > Pages > Source: `main` branch, `/ (root)` > Save.
